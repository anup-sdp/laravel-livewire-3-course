fork the repo from Net Ninja(with all branches):

git clone https://github.com/iamshaunjp/livewire-3-crash-course
cd livewire-3-crash-course
code .

using bash:
git branch -r | grep -v '\->' | sed 's/origin\///' | xargs -n 1 git checkout

see local branches:  git branch -a
see remote branches: git branch -r

git remote set-url origin https://github.com/anup-sdp/laravel-livewire-3-course.git
git remote -v
git push --all origin

~~~~~~~~~~~~~~~~~~~~
after switch/checkout to each branches, run:
php artisan migrate
npm run build 
php artisan serve 
~~~~~~~~~~~~~~~~~~~~
